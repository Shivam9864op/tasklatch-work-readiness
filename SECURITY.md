# Security and privacy

TaskLatch is a personal, local-first demo. It does not have an account system, remote API, analytics, or cloud storage.

## Safe-use boundaries

- Do not paste passwords, one-time codes, government IDs, bank details, private contract text, or full email threads into the demo.
- Store only short, non-sensitive references such as a role ID or task ID. The redacted export removes notes, strips URL paths, and shortens reference IDs.
- A checklist result cannot verify an employer, guarantee an offer, or replace independent checks with the employer or platform.
- “Pause and verify” is a caution signal, not a legal determination that a specific organization is fraudulent.
- The app does not open job links, contact employers, send messages, upload files, or decide whether someone should accept work.

## Reporting an issue

Please open a GitHub issue without including private job, contract, identity, or payment information. For a suspected security issue, contact the repository owner through a public GitHub channel; do not post secrets in an issue.
